# Pollen & Paper: settled design

User delegates defaults without optional interview questions. Preserve fixed-camera mouse-led creative play across paint, stamps, animation and music. Original garden visual language, no Nintendo code, artwork, samples or characters.

- Paint: 160×96 indexed pixels, 16 colors, continuous three-size pencil, connected fill, eraser, transparent stamps, 30-state project undo.
- Stamps: four editable 8×8 prints including three original geometric seeds; shared between painting and animation.
- Animation: four transparent 160×96 frames over a shared painting, copy next frame, selectable 1–12 fps loop, optional own music.
- Music: 16 beats × C4–C5 diatonic pitches, three original synthesizer voices represented by icons, three notes per beat, toggle deletion, 60–200 BPM, loop playback.
- Persistence: versioned validated JSON, local browser autosave, explicit export/import, reversible import, PNG picture export.
- Safeguards: modal before room clear, cancel and undo, reject invalid imports, stop on mode switch or hidden tab.
- Camera: fixed 2D editing surface; responsive display with pointer coordinates mapped to intrinsic pixels. No scrolling within artwork.
- Excluded: motion paths, variable 6/9-frame layouts, sampled animal sounds, exact original timing, coloring book, text, shape tools, patterns, insect game. Core creation and playback take priority.

Tests at authorized seams: model operations and persistence, real browser UI workflows, strict TypeScript/build, independent standards and fidelity review.
