# 0001 — One indexed, versioned creative project

Accepted. Use palette indices for pictures and transparent animation/stamp cells, stored together with notes in validated JSON. This supports deterministic fill, cross-mode reuse and reversible project undo. Raster PNG-only saves would lose editable music and transparent frame structure. The versioned format fixes dimensions and palette order; incompatible future formats require migration rather than silent reinterpretation.
